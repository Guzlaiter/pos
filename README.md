# POS — система учёта продаж

Локальное приложение для магазина, кофейни или небольшой точки услуг: продажи,
смены, склад, прейскуранты и статистика. Работает на Windows с Python 3.12 и
PySide6, данные хранятся в локальной базе SQLite.

## Возможности

- Вход по логину и паролю, роли **администратор** и **продавец**.
- Минимальный экран продавца: каталог, чек, предварительный просмотр и оплата.
- Оплата несколькими способами одновременно: наличные, QR, перевод, терминал.
- Смены с защитой от сбоев: открытая смена и все продажи восстанавливаются
  после перезапуска или отключения питания.
- Закрытие смены с отчётом: выручка, прибыль, оплаты, касса и расхождение.
- Статистика за месяц: выручка, прибыль, средний чек, лидеры по выручке и
  прибыли, продажи по дням, категориям и способам оплаты.
- Товары, услуги, категории, прейскуранты и складские движения.
- Расходники услуг: один материал можно привязать к нескольким услугам, его
  остаток списывается автоматически при продаже.
- Настраиваемые способы оплаты и права продавцов.
- Импорт из старой базы SQLite или CSV с сопоставлением колонок.
- Автоматические резервные копии и проверка целостности базы при запуске.

## Быстрый старт

Требуется [uv](https://docs.astral.sh/uv/) и Python 3.12.

```powershell
uv sync
uv run pos
```

Другие способы запуска:

```powershell
uv run python main.py
uv run python -m pos
```

При первом запуске приложение попросит создать администратора. Пароль должен
содержать не менее 4 символов.

### Демо-данные

```powershell
uv run python -m pos.demo
```

Скрипт создаёт администратора `admin / admin123`, продавца
`seller / seller123` и небольшой каталог. Демо-данные добавляются только в
пустую базу (без пользователей).

## Где хранятся данные

По умолчанию — в папке `data/` рядом с проектом:

| Путь | Назначение |
| --- | --- |
| `data/pos.db` | основная база SQLite |
| `data/backups/` | автоматические резервные копии |
| `data/receipts/` | сохранённые чеки |
| `data/pos.log` | журнал приложения |
| `data/crash.log` | аварийный стек при падении |

Другую папку можно задать переменной окружения `POS_DATA_DIR`:

```powershell
$env:POS_DATA_DIR = "D:\POS\data"
uv run pos
```

Одновременно с одной базой может работать только один экземпляр приложения.
