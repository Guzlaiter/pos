# Статистика

## Где смотреть

- **Статистика** — месячные показатели, график по дням, лидеры, категории и
  способы оплаты.
- **Смены** — список смен с выручкой, прибылью, кассой и расхождением; отчёт
  по выбранной смене.
- **Закрытие смены** — итоги смены и сравнение с месяцем.

## Как считаются показатели

Учитываются только продажи со статусом `completed` (в текущей версии все
успешно сохранённые продажи).

| Показатель | Формула |
| --- | --- |
| **Выручка** | сумма `sale_items.line_total` = цена × количество по всем позициям |
| **Себестоимость** | сумма `cost × qty` по позициям; для услуг `cost` включает израсходованные материалы |
| **Прибыль** | сумма `(unit_price − cost) × qty` |
| **Чеков** | количество уникальных продаж |
| **Продано единиц** | сумма количеств позиций |
| **Средний чек** | выручка / число чеков (целочисленное деление) |
| **Лидер по выручке** | позиция с максимальной суммой `line_total` |
| **Лидер по прибыли** | позиция с максимальной суммой `(unit_price − cost) × qty` |

Цена и себестоимость берутся из снимка в `sale_items`, поэтому изменение
карточки товара задним числом не искажает прошлые отчёты. Для услуг в
себестоимость на момент продажи уже включена стоимость израсходованных
расходников.

## Месячный отчёт

Месяц задаётся годом и номером месяца. В отчёт входят:

- выручка и прибыль;
- число чеков и проданных единиц;
- средний чек;
- продажи по дням (для каждого дня месяца, включая нулевые);
- разбивка по способам оплаты с количеством операций;
- топ позиций по прибыли и выручке;
- разбивка по категориям.

Дни без продаж показываются нулями, чтобы график был стабильным и не
«прыгал».

## Отчёт по смене

Отчёт по конкретной смене содержит:

- выручку, прибыль, число чеков, единиц и средний чек;
- разбивку по способам оплаты;
- ожидаемую кассу, фактическую сумму и расхождение;
- топ позиций по прибыли;
- выручку и прибыль за месяц, в котором закрыта смена;
- лидеров месяца по выручке и прибыли;
- товары с низким остатком.

Если смена ещё открыта, «месяц» берётся по текущей дате. После закрытия — по
дате закрытия.

## Список смен

Для каждой смены показываются: номер, продавец, время открытия и закрытия,
статус, число чеков, выручка, прибыль, фактическая касса и расхождение.
Список отсортирован от новых к старым.

## Товары с низким остатком

Порог задаётся настройкой `low_stock_threshold` (по умолчанию 5). В отчёт
попадают активные товары и расходники со складским учётом, у которых остаток
не больше порога. Услуги в этот список не входят.

## Ограничения

- Отчёты строятся по локальной базе одного компьютера.
- Возвраты и сторнирование продаж в текущей версии не реализованы; если они
  появятся, в формулах нужно будет учитывать статус продажи.
- Прибыль зависит от заполненной себестоимости. Если себестоимость равна
  нулю, прибыль будет равна выручке по этой позиции — заполняйте карточки
  товаров, услуг и расходников.
- Средний чек округляется вниз до копейки из-за целочисленного деления.
