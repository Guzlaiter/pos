## Общие принципы

- Все суммы хранятся в **копейках** (`INTEGER`), без чисел с плавающей точкой.
- Продажа, её позиции, оплаты и складские движения записываются одной
  транзакцией: частично сохранённого чека быть не может. Для услуг в ту же
  транзакцию входит списание расходников по составу услуги.
- Итоги смены не хранятся как счётчики, а каждый раз пересчитываются по
  подтверждённым продажам.
- База работает в режиме WAL с `synchronous=FULL`, поэтому подтверждённая
  продажа переживает отключение питания.
- Резервные копии создаются при запуске, перед импортом и после закрытия смены.
