# Руководство администратора

## Первый запуск

При первом запуске создайте администратора: имя, логин и пароль (не менее
4 символов). После входа доступны все разделы. Способы оплаты и основной
прейскурант создаются автоматически.

## Разделы

### Продажа

Экран продавца доступен и администратору. Здесь можно быстро оформить чек,
проверить работу каталога и оплаты.

### Товары и услуги

Позволяет создавать и редактировать позиции:

- название и артикул (артикул уникален, если заполнен);
- тип: товар или услуга;
- категория;
- цена продажи и себестоимость;
- единица измерения;
- складской учёт (только для товаров);
- активность (снятая с продажи позиция не появляется у продавца).

Себестоимость важна для статистики прибыли. Если оставить её нулевой, прибыль
по позиции будет равна выручке.

### Расходники услуг

Расходники — это материалы, которые тратятся при оказании услуг: бумага,
тонер, плёнка, пакеты и т. п. Они учитываются на складе, но не продаются
отдельно.

Как настроить:

1. Откройте «Товары и услуги» → «Добавить позицию».
2. Создайте товар, например «Бумага Снегурочка A4», укажите единицу «лист»,
   себестоимость и начальный остаток.
3. Отметьте **«Это расходник (материал для услуг, не продаётся)»** и сохраните.
4. Откройте карточку услуги, например «Копия ч/б».
5. В блоке **«Расходники услуги»** нажмите «Добавить расходник», выберите
   бумагу и укажите количество на одну услугу (например, 1 лист).
6. Сохраните услугу. Второй услуге можно назначить тот же расходник с другим
   количеством.

Один расходник может использоваться любым числом услуг — остаток у него общий.
При продаже услуги материал списывается автоматически, а в истории склада
появляется движение «Расходник по услуге». Если материала не хватает, продажа
не сохраняется.

Стоимость расходников автоматически прибавляется к себестоимости услуги при
продаже. Не указывайте стоимость тех же материалов в себестоимости услуги
повторно: иначе она будет учтена дважды.

Фильтр «Расходники» в списке позиций и флажок «Только расходники» на складе
помогают быстро найти материалы. Расходники не показываются продавцу и не
участвуют в прейскурантах.

### Категории

Категории упорядочиваются и могут быть типа «товар», «услуга» или «любой».
Тип помогает не смешивать группы. Удаление категории не удаляет товары: они
остаются без категории.

### Прейскуранты

Прейскурант задаёт цены для позиций. Есть основной (базовый) список; можно
создать дополнительные (например, «Оптовый» или «Сотрудники») и переключать
активный. Цена из активного прейскуранта имеет приоритет над ценой в карточке
товара. Активный прейскурант нельзя удалить — сначала переключитесь на другой.

### Склад

Раздел показывает остатки и историю движений. Доступны операции:

- **приход** — увеличение остатка;
- **списание** — уменьшение остатка (не больше текущего);
- **инвентаризация** — установка фактического остатка;
- история с фильтрами по товару и виду операции;
- флажок **«Только расходники»** — показать только материалы услуг.

Все движения сохраняются с пользователем, датой и комментарием. Остаток нельзя
изменить «молча»: любая корректировка остаётся в истории. Продажа услуги также
создаёт движение «Расходник по услуге».

### Способы оплаты

Список способов оплаты на экране продавца. Для каждого задаются:

- название;
- тип (`cash`, `qr`, `transfer`, `terminal`, `other`);
- признак «влияет на кассу» — такие оплаты входят в ожидаемую наличность;
- порядок сортировки;
- активность.

Должен остаться хотя бы один активный способ оплаты. Отключённый способ не
предлагается продавцу, но остаётся в старых чеках.

### Статистика

Месячная выручка, прибыль, средний чек, продажи по дням, категориям и способам
оплаты, лидеры по выручке и прибыли. Подробнее —
[статистика](statistics.md).

### Смены

Список смен, отчёты, открытие своей смены и закрытие смены (своей или, при
праве `manage_shifts`, чужой). Подробнее — [смены](shifts.md).

### Пользователи

Создание администраторов и продавцов, выдача дополнительных прав, смена
пароля, включение и отключение учётных записей. Нельзя остаться без активного
администратора или отключить себя.

### Импорт данных

Пошаговый импорт из SQLite/CSV с сопоставлением колонок и предпросмотром.
Подробнее — [импорт](import.md).

### Настройки

- название, адрес и телефон организации — для шапки чека;
- валюта;
- текст внизу чека;
- порог низкого остатка;
- число хранимых резервных копий;
- создание копии при запуске;
- кнопки «Создать копию», «Проверить целостность», «Папка данных».

## Настройки в базе

| Ключ | Значение по умолчанию | Смысл |
| --- | --- | --- |
| `company_name` | `Моя компания` | название в чеке |
| `company_address` | пусто | адрес в чеке |
| `company_phone` | пусто | телефон в чеке |
| `currency` | `₽` | символ валюты |
| `receipt_footer` | `Спасибо за покупку!` | подпись чека |
| `low_stock_threshold` | `5` | порог низкого остатка |
| `backup_keep` | `20` | сколько копий хранить (3–200) |
| `backup_on_start` | `1` | копия при запуске |

## Резервные копии и обслуживание

- Копии создаются при запуске, перед импортом и после закрытия смены.
- В настройках можно создать копию вручную и проверить целостность.
- Папка данных открывается кнопкой — удобно для копирования на флешку.
- Для защиты от поломки диска регулярно копируйте `data/backups/` на другой
  носитель.
- Восстановление описано в [документе о базе](database.md).

## Типичные операции

### Добавить товар

1. «Товары и услуги» → «Добавить».
2. Заполните название, цену и себестоимость.
3. Выберите категорию и тип «Товар».
4. Включите складской учёт и укажите начальный остаток.
5. Сохраните.

### Изменить цены

- Для одной позиции — откройте её карточку и измените цену.
- Для группы — создайте прейскурант, задайте цены и сделайте его активным.
- Расходники в прейскурантах не участвуют: у них важна себестоимость, а не
  цена продажи.

### Принять товар

1. «Склад» → выберите товар или отфильтруйте расходники.
2. «Приход», количество и комментарий (например, номер накладной).
3. Сохраните. Остаток увеличится, движение попадёт в историю.

### Закрыть день

1. Проверьте продажи и отчёты.
2. Закройте смену, пересчитав наличные.
3. Сверьте расхождение.
4. При необходимости создайте резервную копию и скопируйте её на внешний
   носитель.
